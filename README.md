# AceIT — Student Academic Planner & GPA Tracker

## Project Description
AceIT is an all-in-one web-based academic organization platform built for university students. It streamlines semester management by combining syllabus deadline tracking, an interactive assignment calendar, weighted course gradebooks, and predictive GPA calculation into a single responsive interface.

## Major Features
* **Course Management:** Add, edit, and organize semester courses with credit hours, instructor info, and meeting times.
* **Syllabus & Assignment Tracker:** Log assignments, exams, and projects with due dates and syllabus weight categories.
* **Interactive Calendar:** View upcoming deadlines across daily, weekly, and monthly views with color-coded course tags.
* **Weighted Gradebook:** Automatically calculate current standing in each class based on weighted categories (e.g., Exams 40%, Quizzes 20%, Homework 40%).
* **GPA Calculator:** Compute semester and cumulative GPA dynamically based on credit hours and letter grades.

## Technologies Used

* **Backend / Runtime:** Node.js, Express.js
* **Database:** SQLite / LocalStorage (Prototype phase)
